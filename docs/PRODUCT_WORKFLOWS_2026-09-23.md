# WriteOff: review, tax position and accountant handoff

Implementation branch: `codex/2027-tax-coverage`, stacked draft PR 13. These changes are implemented and checked locally; this document does not claim a staging or production rollout.

## What users can do

1. **Home:** see the validated federal estimate, confirmed expenses and at most three prioritized next steps. Activity and charts stay collapsed until opened. No new estimated savings are manufactured from unconfirmed charges.
2. **Review:** answer the missing question or save a relevant transaction detail; the saved revision durably schedules a fresh AI review. Repeated unchanged answers do not schedule duplicate work. Existing classifications and receipts are retained. Confirming a suggestion remains an explicit user action.
3. **Ask about this account:** assistant actions find open reviews or missing receipt attachments, show the shared federal calculation, compare it with the previous successful assistant check, and open Filing Hub. A strict model-selected tool list cannot accept another user's ID, executable instructions, external URLs, or financial writes. Owner-verified record reads fail on incomplete queries. Checklist scans cover up to 500 dated owner-tagged records, with the boundary visible. Legal questions and photos retain reviewed conditions and official citations.
4. **Complete common eligibility questions:** year-bound HSA, non-Marketplace self-employed health insurance, supported owner-only retirement plans and joint W-2 ownership feed the same annual JSON/PDF/quarterly engine. Saved claims reconcile to the supporting answers; unknown or unsupported cases remain review gates. See [deduction eligibility](DEDUCTION_ELIGIBILITY_2026-09-23.md).
5. **Give the preparer one package:** Premium/trial users can download a selected-year ZIP including source records, original owned receipt files, checksums and unresolved items, or explicitly create an immutable link expiring within seven days. Links can be revoked even after plan expiry. Basic retains extended history; it does not gain paid exports. Expired/revoked private snapshots receive bounded hourly cleanup after the new function is deployed. See [handoff details](PREPARER_HANDOFF_2026-09-23.md).
6. **Reuse evidence:** import a saved `.eml` receipt attachment or `.ics` event, preview it and confirm the selected attachment or edited business purpose. This uses no inbox/calendar access. See [evidence intake](EVIDENCE_INTAKE_2026-09-23.md).

## Release and remaining scope

Deploy this exact integrated branch's application, Firestore/Storage rules and `analysis` Functions codebase together, including `cleanupExpiredPreparerHandoffs`. Verify the scheduled job's permissions, default receipt bucket, execution and failures in the target environment; local tests do not establish deployed retention. The new assistant query uses the existing transaction owner/date indexes. Apply the repository's current release preflight and provider/bank/billing cutover requirements before production deployment.

The local walkthrough uses fictitious `demo@writeoff.example` data and Firebase emulators. It does not sign into or modify a real user's account. Provider tests used the explicitly connected server OpenAI configuration; no secret is included in these artifacts.

Automatic inbound email forwarding still needs an owned inbound mail domain, verified provider/webhook setup and owner routing. Continuous calendar sync still needs a read-only OAuth consent flow. File imports are available now. The app does not automatically file tax returns; e-filing still requires the separate provider/onboarding/legal authorization workflow. Unpublished 2027 annual tax parameters and unsupported tax scenarios remain gated. Competing well with other products requires observed user outcomes and reliability; this release does not establish market superiority.
